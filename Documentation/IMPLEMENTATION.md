# 기획 적용 내역

## 사용한 문서

`구현 지침.txt`, `스테이지.csv`, `타워 정보.csv`, `타워 정보.xlsx`, `업그레이드.xlsx`, `구성요소` 아래의 모든 텍스트 문서. 제외 요청된 `백로그.txt`와 `스테이지.xlsx`는 읽거나 구현 근거로 사용하지 않았습니다.

## 우선순위 및 보완값

1. **채굴량 충돌:** 기본 설정에는 초당 10개·저장 50개, 건물별 표에는 초당 5개·저장 10개가 있습니다. 구체적인 건물별 표의 5/10을 적용했습니다.
2. **스테이지 7 보상:** 유효한 CSV의 보상 칸이 비어 있어 0G로 두었습니다. 다른 스테이지 수치는 CSV 그대로입니다.
3. **돌/화살 공장:** 텍스트에서 가공품과 에셋은 존재하지만 해당 레시피 행이 빠져 있습니다. 돌 1 → 동그란 돌 1, 쇠 1 → 화살 1, 초당 1개, 입출력 각 5개로 보완했습니다.
4. **구매 가격:** 강화 표의 레벨 0 가격을 기존 건물의 구매 기본값으로도 사용했습니다. 돌 공장 200G, 화살 공장 300G, 공장 가속소 400G, 타워 증폭기 350G는 보완값입니다. 가격과 강화 비용은 독립 설정입니다.
5. **생산 강화:** 공장은 레벨당 생산 주기 0.1초 감소(최소 0.1초). 냉기는 레벨당 둔화 10%p, 화력은 레벨당 피해 10 추가입니다. 세 번째 레벨의 효과가 비어 있는 부분은 이 증가 규칙을 이어 사용했습니다.
6. **타워 강화:** 표의 레벨 1/2 효과인 +20/+30을 반영했습니다. 표의 레벨 3 효과는 비어 있어 직전 단계와 같은 +30으로 보완했습니다. 골드만 소모하고 성능이 그대로인 강화를 피하기 위한 보완값이며, `damageIncreases`에서 변경할 수 있습니다.
7. **시작 가능 건물·한도·해금:** 구체적인 표가 없어 기본 생산 건물·새총·궁수를 시작에 사용하고, 1단계 후 제련소, 2단계 후 총알 공장·총, 3단계 후 가속소·증폭기를 해금합니다. 채굴장 각 3, 공장·제련소 각 4, 각 타워 6, 가속소 2, 증폭기 3, 도로 무제한입니다.
8. **버프 건물:** 인접 공장 생산 25% 가속, 같은 타워 구역 공격 속도 20% 증가로 보완했습니다. 같은 버프 종류는 한 번만 적용합니다.
9. **둔화 지속시간:** 별도 수치가 없어 2초로 두고 피격 시 갱신합니다. 투사체 속도는 초당 22칸입니다.
10. **회수·재도전·저장:** 건물 회수 시 구매·강화 투자금 전액 반환, 클리어 스테이지 재도전 시 같은 클리어 골드 지급, 패배 시 건물 유지로 정했습니다. 처치당 골드는 문서에 없어 추가하지 않았습니다.
11. **혼합 레시피:** 입력 총 저장량은 5개를 유지하면서 다른 필수 재료를 위한 빈자리를 예약합니다. 한 종류의 재료만 가득 차서 조합이 영구 정지하는 상황을 방지합니다.
12. **진행 단위:** 타워 사거리와 몬스터 속도는 격자 칸 단위입니다. 화면의 72 UI 단위 타일은 64px 스프라이트 기준 타일을 확대 표현한 것입니다.

## 유지보수

도메인 전이는 기존 상태를 변경하지 않고 새 상태를 반환합니다. Unity 씬 변경, 입력, 저장, 사운드는 Presentation에서 처리합니다. 반복문과 데이터 클래스 위주로 구성해 동작 추적이 쉽도록 했습니다. 최적화를 위한 풀링이나 복잡한 캐시는 도입하지 않았습니다.
