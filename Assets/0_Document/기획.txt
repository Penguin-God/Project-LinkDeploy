===최종 수정일 - 9/16, 8:20===
가로형으로 즐기는 2d 탑다운 픽셀아트 모바일 게임
한줄 요약 : 2차원 정사각형 칸에 건물을 배치해 도로를 연결해 재료를 전달하고 제작해서 타워까지 보내서 적을 막는 게임
테마 : 배치와 연결

===기본 개념===
자원 : 건물을 짓기와 강화에 사용
자원 타입 : 플레이어가 관리하는 자원은 골드, 나무, 철, 망치가 있고 각각 얻는 방법이 다름
자원 획득처 : 골드는 스테이지 클리어마다 지급, 나무, 쇠, 망치는 마을에서 채굴 및 생산을 통해 회관과 연결을 통해 획득

칸 : 건물이 존재할 수 있는 격자 공간
건물 : 칸에 배치 가능하고 각 고유한 타입과 동작을 가지는 것
건물 타입 : 채굴장, 공장, 도로, 타워, 타워 버프
건물 이동 타입 : 자유, 고정
-자유는 이동, 판매 가능. 고정은 불가

===구역===
마을 : 직접적인 방어가 아닌 여러 기능을 가진 건물을 지을 수 있는 공간
-가운데에 고정 타입 건물인 회관이 존재함
-회관 : 레벨업 시 지을 수 있는 건물의 종류가 늘어남. 모든 채굴 자원이 회관과 연결되어야 플레이어에게 지급됨


방어 구역 : 타워에 필요한 투사체를 만들기 위한 채굴장이 존재하고, 공장을 설치할 수 있는 공간
-오직 타워만 설치할 수 공간이 아래에 별도로 존재한다
-타워 구역 : 타워, 타워 버프만 설치할 수 있는 구역. 방어 구역에 입구가 있고, 입구 범위 내에 재료 수급 연결망이 존재하면 구역 전체에 재료 수급


===기본 개념===
건물 설치 : 설치는 로비에서만 가능하며, 지정한 칸에 설치 가능. 설치한 건물이 그대로 디펜스 씬에 적용됨

스테이지 : 진행 가능한 스테이지가 1~5까지 버튼으로 있음. 낮을 걸 깨야 다음으로 넘어갈 수 있음
-스테이지당 몹 체력, 속도, 등장 수, 소환 딜레이, 클리어 획득 골드 등을 따로 설정할 수 있는 SO필요

타워 : 공격력, 공격속도, 사정거리, 총알 수, 총알 타입을 가짐. 공장과 연결되어있는지를 상태로 가짐
-사정거리 안에 있는 적을 추적하는 투사체를 발사함. 공격시 총알 소모, 없으면 대기

투사체 : 오직 지정한 적에게만 충돌 시 대미지를 입힘
몬스터 : HP를 가지며 목적지로 이동함
목적지 : 타워 구역 바로 아래에 직선으로 이동하며 그 끝이 목적지
실패 : 1마리의 몬스터라도 목적지에 도착하면 패배
성공 : 실패하지 않고 모든 몬스터를 잡으면 승리
채굴장 : 위치는 고정되어 있으며 개수는 하나. 기본 자원을 채굴. 초당 n개씩 생성
공장 : 초당 생산수, 레시피, 결과물 타입을 가짐. 레시피 재료들을 소모해 결과물을 만듬
도로 : 연결 범위를 늘리는 건물. 상하좌우 1칸씩 연결 가능
제련소 : 투사체에 효과를 부여하는 등 강화해주는 건물. 어떤 투사체를 강화할지 선택 가능

투사체 강화 공장 : 투사체에 효과를 부여하는 공장. 강화된 재료가 조합에 사용되면 효과는 사라진다
-일반 공장처럼 초당 생산수를 가지지만 레시피가 없이 모든 투사체에 효과를 부여하고 결과물의 투사체 타입이 바뀌지도 않는다

재료 수급 : 본인 혹은 도로가 연결된 곳 중 자신의 재료를 필요로 하는 건물에 전달 가능
-수급은 연결된 범위 안에 있는 건물 중 제일 적은 곳에 공급됨. 다 똑같다면 가까운 것부터

타워 업그레이드 : 타워의 종류마다 다른 플레이어 자원을 필요로 함. 업그레이드 되는 부분도 다름. 자세한 수치는 업그레이드.xlsx파일에 있음. 도로는 강화 불가





===건물 간 연결===
-재료 : 채굴장에서 나오는 기본 재료와 가공되어 나오는 모든 것들
-재료들은 도로나 공장 등의 건물을 통해 방향에 따라 이동한다
-각 건물들은 방향을 가지고 있고 설치 시 R버튼으로 설정가능. 방향에 따라 1칸내에 건물을 검사

-파이프라인 : 공장, 도로, 제련소는 인풋과 아웃풋이 있는 함수로 생각한다. 
-경로에서 Input에 맞는 재료는 받아서 생성 등의 작업이 끝난 후에 다음으로 이동한다. 작업이 끝나기 전에 저장량이 꽉 차면 이전 흐름은 멈추고 대기해야한다
-Input이 맞지 않는다면 건물에 들어가지 않고, 흐름이 막힌다
-도로는 인풋에 제한이 없고 작업도 없기에 시간도 없다, 제련소는 모든 투사체며 공장은 지정되어 있다

-결과 재료가 있는 건물은 셧다운이 존재함. 사용 재료 0이 되면 꽉 차야지만 사용 가능. 
-셧다운 시 채굴장은 채굴한 재료가 전달되지 않음(채굴은 함), 공장은 결과물이 전달되지 않음(제작은 함), 타워는 공격을 못함

===UI/UX===
-버프와, 도로 등 주변에 영향을 주는 건물들은 클릭 시 주위에 연한 초록색으로 범위 표기. 다른 아무 클릭이나 받으면 표기 멈춤
-타워의 범위는 그냥 거리로 보여야 함
-재료는 건물 위에 현재 총알/최대 총알 식으로 표기되어야함. 재료가 바닥나 셧다운 상태면 텍스트가 빨간색으로 변함
-타워 구역은 입구에서 도로가 하나 더 튀어나와 있고 거기와 연결되어 있는 구역. 튀어나와있는 도로는 별도 기능 없는 시각적 구분선
-아웃풋 재료는 건물 위에 현재 양/최대 수용량으로 숫자표기

-마을 구역이 방어 구역 위에 있음
-방어 구역과 마을은 버튼 클릭을 통해서 토글 형식으로 화면 전환 가능. 버튼은 오른쪽 아래에 위치함

-로비-
-화면 상단에 현재 골드, 철, 나무, 못 개수 표기되어야 함
-일반 상태에서 건물 클릭시 가운데 아래쪽에 판매 버튼이 나오고 원래 금액의 90%로 판매 가능. 버튼은 평소에는 숨김 상태
-모드 관계없이 건물 클릭, 혹은 건축모드에서 특정 건물을 짓고 있을 때 왼쪽 가운데에 네모난 판넬 팝업 설명창이 뜸
-설명창 아래 가운데에 강화 버튼이 있음. 현재 레벨(강화 골드) 형식으로 표기
-상단은 건물 이름, 가운데에 엑셀 파일에 있는 설명이 뜸

-건축 모드-
-건축 모드 버튼을 누르면 모든 설치 가능 건물이 설치 구역에 따라 카테고리로 분리되어 배치됨
-건물 버튼을 클릭하면 설치모드로 바뀜. 설치해도 지속됨. 취소 버튼 클릭 or 우클릭 시 취소
-건물에 따라 설치할 수 없는 칸은 연한 빨간색으로 표기, 설치 가능 칸은 연한 초록색
-지을 수 없는건 비활성화. 지을 수 있는건 오른쪽 밑에 XN형식으로 얼마나 지을 수 있는지 표기
-드래그로 건물 위치 변경 가능. 비어있는 곳에만 이동 가능
-구역에서 지을 수 있는 건물만 버튼으로 표기되어야 함
